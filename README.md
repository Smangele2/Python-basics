# Python Basics - By Smangele

Collection of beginner Python functions built while learning to code.

## What's inside
- `greet(name)` - returns greeting message
- `is_even(n)` - checks if number is even
- `filter_evens(numbers)` - filters even numbers from list
- `sum_numbers(numbers)` - sums all numbers
- `get_long_names(names)` - filters names longer than 5 chars

## Tech
Python 3 - loops, conditionals, list operations
